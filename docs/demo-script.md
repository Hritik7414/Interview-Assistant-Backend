# Demo recording outline (3–5 minutes)

1. **0:00–0:30 — Set up.** Show Demo Mode, the resume and job-description
   fields, and the microphone or simulated input choice. State that demo output
   is labelled as simulated.
2. **0:30–1:15 — Start.** Start listening. Show the connection and session
   states, live transcript, and how small talk is ignored.
3. **1:15–3:30 — Three questions.** Let the scripted introduction, system
   design, and behavioral/testing questions appear. Show the detected question
   and answer streaming for each; point out the answer length and context use.
4. **3:30–4:15 — Diagnostics and stop.** Show latency metrics and stop the
   session cleanly.
5. **4:15–5:00 — Trade-offs.** Briefly explain that the demo uses simulated
   providers, while Live Mode needs Deepgram and an OpenAI-compatible API key.
